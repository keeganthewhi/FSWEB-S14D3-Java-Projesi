# Polymorphism

> Full Stack Web Development Bootcamp — Sprint 14, Day 3

![Java](https://img.shields.io/badge/Java-ED8B00?style=flat-square&logo=openjdk&logoColor=white)

## About

Explores polymorphism in Java, demonstrating how objects of different types can be treated uniformly through shared interfaces or parent classes. Covers both compile-time and runtime polymorphism.

## Key Concepts

- Runtime polymorphism (method overriding)
- Compile-time polymorphism (method overloading)
- Upcasting and dynamic dispatch
- Writing flexible, extensible code with polymorphism
